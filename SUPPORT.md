# Support

For setup or provider problems, first open:

```text
Lean Quota Monitor
→ Troubleshoot
→ Provider
→ Setup Method
```

The selected method shows the current failure and the actual lookup target used by the active VS Code Extension Host.

If the issue remains, open a GitHub issue:

https://github.com/nicezic/lean-quota-monitor/issues

Please include:

- VS Code version
- operating system / Extension Host (`linux`, `win32`, or `darwin`)
- provider name
- the safe error code/message shown by Troubleshoot
- the Acquisition Path id when available

Do **not** include API keys, OAuth/access/refresh tokens, cookies, raw credential files, or other secret values.

If possible, use your AI coding assistant to prepare a fix and open a PR — contributions are very welcome and actively reviewed.
